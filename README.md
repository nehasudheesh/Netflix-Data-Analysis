# Netflix Data Analysis

## Project Overview

This project analyzes Netflix Movies and TV Shows data using Python.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed

- Data Cleaning
- Movies vs TV Shows
- Top Countries
- Top Ratings
- Genre Analysis
- Release Year Analysis

## Key Insights

- Netflix contains more Movies than TV Shows.
- Content increased rapidly after 2015.
- USA contributes the highest amount of content.
- TV-MA is one of the most common ratings.

## Dataset

Netflix Titles Dataset from Kaggle.
